
# 🎲 RandomBox

A lightweight all-in-one random generator web application built with Python.

## Features

- Random number generator
- Random item picker
- Coin flip simulator
- Dice roller
- Secure random password generator
- Clean and responsive interface
- No external dependencies

## Requirements

- Python 3.8+

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/randombox.git
cd randombox
```

## Usage

Run the application:

```bash
python app.py
```

Open your browser:

```text
http://127.0.0.1:8000
```

- Python
